# A draft with a memory you can inspect

[Watch the actual UI tour](media/workspace-ui-tour.mp4) · [English captions](media/workspace-ui-tour.en.vtt).

The silent 25-second walkthrough is an edited sequence of five actual application
screenshots, rather than a continuous screen recording.

All Harbor names, dates, numbers and events in these screenshots are invented.
The stored facts were entered manually, and the draft was prepared for the tour.
No private corpus or live model result appears in the media.

1. Open **Harbor · Weekly update**. Earlier kickoff, decision and field notes
   remain separate documents. The **Materials** tray holds selected evidence,
   while related memory retrieves relevant saved facts near the current paragraph.
2. Put the cursor where a source quotation belongs. Click **Quote** beside a
   recalled fact. The original text is inserted with its source identifier.
3. Open the fact. Its date and **Original words** make the source evidence
   inspectable independently of the draft.
4. Open **Writing mode**. A template specifies sourcing, writing, checks and
   finish rules. A custom task supplies a goal, audience and completion criteria.
5. Open **Import** to see the supported paths for existing notes and documents.

To try the agent loop, configure a model in Settings, select the material and
start Smart Continue. Choose round-by-round review if you want a decision point
between rounds. This model-driven step is described here but is not performed in
the UI tour. Use snapshots and history to recover earlier text.

The adjacent [architecture introduction](media/agent-native-writing-workspace.md)
explains how KITE memory and the writing agent harness implement this workflow.
