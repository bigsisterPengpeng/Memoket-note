# Conservative planning

For an ambiguous or very broad goal, produce a conservative, focused section list covering only what the user actually requested. Do not infer an exhaustive program from missing boundaries. Later gap review can add justified sections; an oversized initial plan is more likely to drift. Inspired by brainstorming.
