# Verification triage

Before flagging a selection, decide whether verification is useful. Skip purely creative expression, stylistic wording, and uncertainty the user has explicitly acknowledged. Focus on factual assertions about numbers, dates, causes or attribution without direct support. Explain which evidence is missing instead of merely asking for verification.
