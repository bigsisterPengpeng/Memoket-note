# Maple pilot example

All names, events, dates and measurements in these three notes are fictional.
They were written for a reproducible import, memory, writing and export demo.

1. In Import, select **Notes + knowledge base** and choose the three numbered Markdown files in
   `maple-pilot/`, or select that directory as an Obsidian vault.
2. Wait for all three notes to finish. Knowledge extraction uses your configured
   model. Inspect the resulting facts and original evidence in the knowledge base.
3. Close and reopen the workspace. The saved facts remain available locally.
4. Create a note named **Maple weekly update**, select the Weekly report template
   or define a custom task, and begin with `# Maple weekly update`.
5. Ask for a short update for the pilot team covering the current plan, rehearsal
   evidence, the blocker and the next action. Use the saved Maple sources, preserve
   uncertainty, cite evidence and avoid inventing owners or a public launch date.
6. Run Smart Continue, inspect source links and review the edits.
7. Use **Export** to download Markdown or write into a separate local Obsidian
   vault. Compare the exported draft with the editor and inspect its source IDs.

Model output varies. The recording shows one actual run, not an output guarantee.
The reviewed example's source IDs belong to that recorded library; verify or
regenerate citations after a fresh import.
Notion and Apple Notes appear as available import options, but this recording
uses local Markdown files and does not connect to personal accounts.
